🚀 Applio Voice Training Script

One script that turns your recordings into a voice model: preprocess, extract features, train, make the index, and try the new voice on a test file. The voice name is a variable, so you change it in one place.

The script

train_voice.bat
@echo off
setlocal EnableExtensions

rem ==========================================================================
rem  train_voice.bat  -  make an Applio voice model, from recordings to a .pth
rem
rem  Put this file in the Applio folder (for example C:\Tools\Applio) and
rem  double-click it, or run it from Command Prompt:
rem
rem      train_voice.bat [MODEL_NAME] [DATASET_FOLDER] [TOTAL_EPOCHS]
rem
rem  Examples:
rem      train_voice.bat
rem      train_voice.bat john C:\john-recordings
rem      train_voice.bat john C:\john-recordings 150
rem
rem  Anything you do not type uses the SETTINGS below.
rem  Steps: 1 preprocess, 2 extract, 3 train (also writes the index), 4 check.
rem  Each step is checked by looking for the files it should have made,
rem  because Applio can print "success" and still produce nothing.
rem ==========================================================================

rem ---------------------------- SETTINGS ------------------------------------
rem Voice name. Use letters, numbers, _ and - (no spaces).
set "MODEL=myvoice"
rem Folder with your recordings (.wav .mp3 .flac .ogg) directly inside it.
set "DATASET=C:\voice-data"
rem 5 = quick test only (rough voice). Try 150 or more for a real voice.
set "EPOCHS=5"
rem Save a checkpoint every N epochs.
set "SAVE_EVERY=1"
rem Lower this (4, 2) if you get "out of memory".
set "BATCH=4"
rem Must be the same in every step. Applio accepts 32000, 40000 or 48000.
set "SAMPLE_RATE=40000"
rem 1 = delete logs\MODEL first (starts this voice from zero, asks to confirm).
set "FRESH=0"
rem Optional: a short WAV to try the finished voice on. Leave empty to skip.
set "TEST_WAV=C:\test\in.wav"
set "TEST_OUT=C:\test\out.wav"
rem --------------------------------------------------------------------------

if not "%~1"=="" set "MODEL=%~1"
if not "%~2"=="" set "DATASET=%~2"
if not "%~3"=="" set "EPOCHS=%~3"
rem A trailing backslash would break the quoted path, so remove it.
if "%DATASET:~-1%"=="\" set "DATASET=%DATASET:~0,-1%"

rem Always work from the folder this file is in.
cd /d "%~dp0"
set "PY=env\python.exe"
set "LOGS=logs\%MODEL%"

echo.
echo ===== Applio voice training =====
echo Applio folder : %CD%
echo Voice name    : %MODEL%
echo Recordings    : %DATASET%
echo Epochs        : %EPOCHS%   Batch size: %BATCH%   Sample rate: %SAMPLE_RATE%
echo.

rem ---- Checks before starting ----
if not exist "%PY%" (
    echo ERROR: %PY% not found. Put this file in the Applio folder.
    goto :fail
)
if not exist "core.py" (
    echo ERROR: core.py not found. Put this file in the Applio folder.
    goto :fail
)
if not exist "%DATASET%\" (
    echo ERROR: the recordings folder does not exist: %DATASET%
    goto :fail
)
set "FOUND="
for %%e in (wav mp3 flac ogg) do if exist "%DATASET%\*.%%e" set "FOUND=1"
if not defined FOUND (
    echo ERROR: no .wav .mp3 .flac or .ogg files directly inside %DATASET%
    echo        Applio ignores .m4a. Convert it first, for example:
    echo        ffmpeg -i clip.m4a -ar 44100 -ac 1 clip.wav
    goto :fail
)

rem ---- Is a working NVIDIA GPU available? ----
set "HASGPU=0"
for /f %%i in ('%PY% -c "import torch;print(int(torch.cuda.is_available()))" 2^>nul') do set "HASGPU=%%i"
set "GPUARG="
if "%HASGPU%"=="1" (
    set "GPUARG=--gpu 0"
    echo GPU          : found, will be used
) else (
    echo GPU          : none usable, using the CPU - this is slow
)
echo.
echo Starting in 5 seconds. Press Ctrl+C to cancel.
timeout /t 5 >nul

if "%FRESH%"=="1" (
    if exist "%LOGS%" (
        echo.
        echo WARNING: FRESH=1 will delete everything in %LOGS%
        echo          including earlier checkpoints and models of this voice.
        set "ANS="
        set /p "ANS=Type YES to delete it, anything else cancels: "
        if /i not "%ANS%"=="YES" (
            echo Cancelled. Nothing was deleted.
            goto :fail
        )
        rmdir /s /q "%LOGS%"
    )
)

rem ================= 1. Preprocess =================
echo.
echo ===== [1/4] Preprocess recordings =====
"%PY%" core.py preprocess --model-name "%MODEL%" --dataset-path "%DATASET%" --sample-rate %SAMPLE_RATE%
if errorlevel 1 goto :fail
if not exist "%LOGS%\sliced_audios\*.wav" (
    echo ERROR: preprocess made no audio slices in %LOGS%\sliced_audios
    goto :fail
)

rem ================= 2. Extract features =================
echo.
echo ===== [2/4] Extract features =====
rem Remove old results first so nothing stale is reused.
if exist "%LOGS%\extracted"  rmdir /s /q "%LOGS%\extracted"
if exist "%LOGS%\f0"         rmdir /s /q "%LOGS%\f0"
if exist "%LOGS%\f0_voiced"  rmdir /s /q "%LOGS%\f0_voiced"
if exist "%LOGS%\filelist.txt" del /q "%LOGS%\filelist.txt"
"%PY%" core.py extract --model-name "%MODEL%" --sample-rate %SAMPLE_RATE% %GPUARG%
if errorlevel 1 goto :fail
if not exist "%LOGS%\extracted\*.npy" (
    echo ERROR: extraction wrote no feature files. Applio said "success" anyway.
    echo        Read the messages above, especially any CUDA or driver warning.
    goto :fail
)
if not exist "%LOGS%\filelist.txt" (
    echo ERROR: filelist.txt was not created.
    goto :fail
)
set "FSIZE="
for %%F in ("%LOGS%\filelist.txt") do set "FSIZE=%%~zF"
if "%FSIZE%"=="0" (
    echo ERROR: filelist.txt is empty, so there is nothing to train on.
    goto :fail
)

rem ================= 3. Train =================
echo.
echo ===== [3/4] Train - this is the long step, do not close the window =====
rem Applio keeps an existing index and does not rebuild it, so move an old one
rem aside; training then writes a new index that matches the new data.
if exist "%LOGS%\%MODEL%.index" (
    move /y "%LOGS%\%MODEL%.index" "%LOGS%\%MODEL%.index.bak" >nul
    echo Old index kept as %MODEL%.index.bak
)
"%PY%" core.py train --model-name "%MODEL%" --sample-rate %SAMPLE_RATE% --save-every-epoch %SAVE_EVERY% --total-epoch %EPOCHS% --batch-size %BATCH%
if errorlevel 1 goto :fail

rem ================= 4. Check results =================
echo.
echo ===== [4/4] Check the results =====
set "LATEST="
for /f "delims=" %%F in ('dir /b /o:d "%LOGS%\%MODEL%_*e_*s.pth" 2^>nul') do set "LATEST=%%F"
if not defined LATEST (
    echo ERROR: no %MODEL%_*e_*s.pth model file was written.
    goto :fail
)
rem Training normally writes the index at the end. Make it if it is missing.
if not exist "%LOGS%\%MODEL%.index" (
    echo Index missing, creating it now...
    "%PY%" core.py index --model-name "%MODEL%"
)
set "HAVEINDEX=0"
if exist "%LOGS%\%MODEL%.index" set "HAVEINDEX=1"

set "PTH=%CD%\%LOGS%\%LATEST%"
set "IDX=%CD%\%LOGS%\%MODEL%.index"

rem ---- Optional quick test ----
if defined TEST_WAV if exist "%TEST_WAV%" (
    echo.
    echo Trying the voice on %TEST_WAV%
    if exist "%TEST_OUT%" del /q "%TEST_OUT%"
    if "%HAVEINDEX%"=="1" (
        "%PY%" core.py infer --input-path "%TEST_WAV%" --output-path "%TEST_OUT%" --pth-path "%PTH%" --index-path "%IDX%"
    ) else (
        "%PY%" core.py infer --input-path "%TEST_WAV%" --output-path "%TEST_OUT%" --pth-path "%PTH%" --index-path ""
    )
    if exist "%TEST_OUT%" (
        echo Test result written to %TEST_OUT%
    ) else (
        echo WARNING: the test did not produce %TEST_OUT%
    )
)

rem ---- Print the lines for appsettings.json (backslashes doubled) ----
set "PTHJ=%PTH:\=\\%"
set "IDXJ=%IDX:\=\\%"
echo.
echo ==========================================================
echo  DONE. Voice "%MODEL%" is ready.
echo  Put these in WebDownload.Server\appsettings.json, VoiceSwap, Models:
echo.
echo     "PthPath": "%PTHJ%",
if "%HAVEINDEX%"=="1" (
    echo     "IndexPath": "%IDXJ%",
) else (
    echo     "IndexPath": "",
)
echo ==========================================================
echo.
pause
exit /b 0

:fail
echo.
echo ==========================================================
echo  STOPPED. Fix the problem shown above, then run this again.
echo ==========================================================
echo.
pause
exit /b 1

How to use it

  1. Press Download train_voice.bat (or Copy and save it as train_voice.bat) and put the file in your Applio folder, for example C:\Tools\Applio.
  2. Put your recordings in one folder, for example C:\voice-data. Use .wav, .mp3, .flac or .ogg files directly inside it. Applio ignores .m4a.
  3. Double-click the file, or run it in Command Prompt. The three values are the voice name, the recordings folder and the number of epochs; anything you leave out uses the settings at the top of the script:
    Command Prompt
    train_voice.bat myvoice C:\voice-data 150
  4. When it finishes it prints the PthPath and IndexPath lines to paste into the VoiceSwap section of appsettings.json.

Settings at the top of the script

MODELThe voice name. Letters, numbers, _ and -, no spaces. Change it here, or type it after the file name.
DATASETThe folder with your recordings.
EPOCHS5 is a quick test and gives a rough voice. Try 150 or more for a real one.
SAVE_EVERYSave a checkpoint every this many epochs.
BATCHLower it (4, 2) if you get an out-of-memory error.
SAMPLE_RATEThe same value is used in every step. Applio accepts 32000, 40000 or 48000.
FRESH1 deletes the voice's folder first. It asks you to type YES.
TEST_WAVA short WAV to try the finished voice on. Leave it empty to skip.

What the script protects you from

  • "Success" without results. Applio can report that a step worked and write nothing, for example when the GPU driver is too old. The script checks for the files each step should create and stops with a clear message.
  • No usable GPU. It checks for one itself and uses the CPU otherwise. Training on the CPU works but is slow.
  • Unsupported recordings. It stops before Applio runs if the folder holds no .wav, .mp3, .flac or .ogg files.
  • An old index. Applio does not rebuild an index that already exists, so the script moves it aside as .index.bak and a fresh one is made when you retrain.

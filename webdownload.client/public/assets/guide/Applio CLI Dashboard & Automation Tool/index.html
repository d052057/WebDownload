Applio Custom Variable CLI Dashboard

A flexible fallback script configured for your specific installation directory at c:\tools\applio.

🚀 Full Pipeline Script (Fully Variable-Driven)

You can adjust any parameter in the variables block below. Copying and pasting this block directly into a single Command Prompt window will jump to your Applio path and safely run every step consecutively.

@echo off :: ========================================== :: CUSTOM VARIABLES BLOCK :: ========================================== set APPLIO_DIR=c:\tools\applio set MODEL_NAME=MyCustomVoice set DATASET_PATH=assets\datasets\MyCustomVoice set INPUT_AUDIO=assets\audios\input_song.wav set OUTPUT_AUDIO=assets\audios\output_voice_boosted.wav :: --- Training Parameters --- set SAMPLE_RATE=40000 set RVC_VERSION=v2 set PITCH_ALGO=rmvpe set TOTAL_EPOCHS=200 set BATCH_SIZE=4 set SAVE_FREQUENCY=10 :: --- Volume & Pitch Adjustments --- set VOLUME_BOOST=6.0 set PITCH_CHANGE=0 :: ========================================== :: AUTOMATED PIPELINE EXECUTION :: ========================================== echo [0/5] Changing directory to Applio... cd /d "%APPLIO_DIR%" echo [1/5] Pre-processing Dataset... env\python.exe core.py preprocess --model_name "%MODEL_NAME%" --dataset_path "%DATASET_PATH%" --sampling_rate %SAMPLE_RATE% echo [2/5] Extracting Pitch Features (%PITCH_ALGO%)... env\python.exe core.py extract --model_name "%MODEL_NAME%" --rvc_version "%RVC_VERSION%" --pitch_algorithm "%PITCH_ALGO%" echo [3/5] Launching Model Training... env\python.exe core.py train --model_name "%MODEL_NAME%" --total_epochs %TOTAL_EPOCHS% --batch_size %BATCH_SIZE% --save_every_epoch %SAVE_FREQUENCY% echo [4/5] Executing Inference with Voice Volume Boost (+%VOLUME_BOOST% dB)... env\python.exe core.py infer --model_name "%MODEL_NAME%.pth" --index_path "logs\%MODEL_NAME%\added_index.index" --input_path "%INPUT_AUDIO%" --output_path "%OUTPUT_AUDIO%" --output_gain %VOLUME_BOOST% --pitch_change %PITCH_CHANGE% echo [5/5] Pipeline Finished! Check your output file: "%APPLIO_DIR%\%OUTPUT_AUDIO%" pause

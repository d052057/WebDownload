IIS Intranet Server Fix

Eliminate network drops and power-throttling when the Windows 10 screen locks.

Applies to Wired Ethernet Connections
STEP 1
Command Prompt (Run as Administrator)

These commands stop Windows from putting components or console sessions to sleep while locked.

:: Disable Console Lock Sleep Timeout
powercfg.exe /setacvalueindex SCHEME_CURRENT SUB_VIDEO VIDEOCONLOCK 0

:: Disable System Unattended Sleep Timeout
powercfg.exe /setacvalueindex SCHEME_CURRENT SUB_SLEEP UNATTENDTIMEOUT 0

:: Set all core standby timeouts to Never
powercfg.exe /change standby-timeout-ac 0
powercfg.exe /change monitor-timeout-ac 0
powercfg.exe /change disk-timeout-ac 0

:: Force active power plan to apply changes immediately
powercfg.exe /setactive SCHEME_CURRENT
STEP 2
Registry Tweaks (Run in Admin Command Prompt)

Unlocks hidden power settings in Control Panel and stops RDP lock disconnects.

:: Unhide "System unattended sleep timeout"
reg add "HKLM\SYSTEM\CurrentControlSet\Control\Power\PowerSettings\7516b95f-f776-4464-8c53-06167f40cc99\8ec4b3a5-6868-48c2-be75-4f3044be88a7" /v Attributes /t REG_DWORD /d 2 /f

:: Unhide "Console lock display off timeout"
reg add "HKLM\SYSTEM\CurrentControlSet\Control\Power\PowerSettings\7516b95f-f776-4464-8c53-06167f40cc99\8ec4b3a5-6868-48c2-be75-4f3044be88a7" /v Attributes /t REG_DWORD /d 2 /f

:: Disable Remote Desktop connection termination on lock
reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows NT\Terminal Services" /v fDisconnectOnLock /t REG_DWORD /d 0 /f
STEP 3
Windows PowerShell (Run as Administrator)

Automatically loops through physical network adapters to disable green power saving features.

Note: Your network link will briefly drop for 2 seconds while this script applies changes. 
# Disable OS power-down control over physical network hardware
Get-NetAdapter | Where-Object {$_.HardwareInterface -eq $true} | ForEach-Object {
    $SysName = $_.InterfaceDescription
    Get-CimInstance -ClassName MSPowerManagement_DeviceEnable -Namespace root\wmi | Where-Object {$_.InstanceName -match [regex]::Escape($SysName)} | Set-CimInstance -Property @{Enable = $false}
}

# Disable Energy Efficient Ethernet and Green settings
Get-NetAdapterAdvancedProperty | Where-Object {$_.DisplayName -like "*Energy*" -or $_.DisplayName -like "*Green*" -or $_.DisplayName -like "*Low Power*"} | Set-NetAdapterAdvancedProperty -RegistryValue "0"
🛠️ Final Requirement
Please restart the computer after executing these blocks to ensure all network infrastructure layers apply the changes seamlessly.

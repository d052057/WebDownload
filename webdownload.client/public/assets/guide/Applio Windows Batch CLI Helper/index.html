Applio CLI Steps & Volume Controls (.BAT Native)

Use these backend commands if the web UI goes offline, freezes, or fails to render. Open a standard command prompt (CMD) inside your Applio folder before running them.

Step 1: Pre-process Dataset

Pre-processes your clean voice recordings located in your dataset folder, matching them to a target sample rate.

env\python.exe core.py preprocess --model_name "MyVoice" --dataset_path "assets\datasets\MyVoice" --sampling_rate 40000

Step 2: Extract Features & Pitch

Extracts essential pitch information using the highly recommended RMVPE algorithm.

env\python.exe core.py extract --model_name "MyVoice" --rvc_version "v2" --pitch_algorithm "rmvpe"

Step 3: Run Model Training

Launches core backend training. Set total epochs (e.g., 200) and batch size according to your graphics card capability.

env\python.exe core.py train --model_name "MyVoice" --total_epochs 200 --batch_size 4 --save_every_epoch 10

Step 4: Inference with Output Volume Boost

Applies voice conversion onto a target source file while bypassing UI limits to apply a hard +6.0 dB output gain boost.

env\python.exe core.py infer --model_name "MyVoice.pth" --index_path "logs\MyVoice\added_index.index" --input_path "assets\audios\input_song.wav" --output_path "assets\audios\output_voice_boosted.wav" --output_gain 6.0 --pitch_change 0

Note: Increase '--output_gain' further (e.g., 8.5) if the volume is still too quiet.

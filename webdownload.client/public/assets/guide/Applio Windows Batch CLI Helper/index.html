Applio Command-Line Steps

Run these in Command Prompt, one at a time, when you want control of each step, or when the web interface will not start. Each box has a Copy button. Applio's option names use hyphens (--model-name), not underscores.

For the same steps in one file, see the Applio CLI Dashboard & Automation Tool guide.

0Set the folder and the voice name
Command Prompt
cd /d C:\Tools\Applio
set MODEL=myvoice
set DATASET=C:\voice-data

Change MODEL once and every step below uses it. Press Enter after pasting if the last line does not run. These settings last until you close the window.

1Preprocess the recordings
Command Prompt
env\python.exe core.py preprocess --model-name "%MODEL%" --dataset-path "%DATASET%" --sample-rate 40000

The folder must hold .wav, .mp3, .flac or .ogg files (not .m4a). You should see Model myvoice preprocessed successfully.

2Extract the features
Command Prompt
env\python.exe core.py extract --model-name "%MODEL%" --sample-rate 40000

This runs on the CPU, which always works. Add --gpu 0 only if step 8 prints True. With a broken GPU driver Applio still says "extracted successfully" but writes nothing, so check: dir logs\%MODEL%\extracted must list .npy files.

3Train the voice
Command Prompt
env\python.exe core.py train --model-name "%MODEL%" --sample-rate 40000 --save-every-epoch 10 --total-epoch 150 --batch-size 4

Applio's default is 1000 epochs; 150 is a starting point. Lower --batch-size if you run out of memory. Training also creates the index at the end. Do not close the window.

4Make the index (only if it is missing)
Command Prompt
env\python.exe core.py index --model-name "%MODEL%"

Skip this when logs\%MODEL%\%MODEL%.index already exists. Applio keeps an existing index and does not rebuild it.

5See what you got
Command Prompt
dir logs\%MODEL%

Look for myvoice_150e_<number>s.pth, the finished voice, and myvoice.index. The large G_*.pth and D_*.pth files are training checkpoints, not voices.

6Try the voice on a recording
Command Prompt
set PTH=myvoice_150e_900s.pth
env\python.exe core.py infer --input-path "C:\test\in.wav" --output-path "C:\test\out.wav" --pth-path "logs\%MODEL%\%PTH%" --index-path "logs\%MODEL%\%MODEL%.index"

Replace myvoice_150e_900s.pth with the real file name from step 5. Without an index, use --index-path "". Add --pitch 12 (or -12) to move the voice up or down an octave.

7Make the voice louder or quieter
Command Prompt
env\python.exe core.py infer --input-path "C:\test\in.wav" --output-path "C:\test\out.wav" --pth-path "logs\%MODEL%\%PTH%" --index-path "logs\%MODEL%\%MODEL%.index" --post-process --gain --gain-db 6.0

Same as step 6 plus the gain options. Both --post-process and --gain are needed. A negative number makes it quieter. If the result sounds distorted, use a smaller number.

8Is the graphics card usable?
Command Prompt
env\python.exe -c "import torch; print(torch.cuda.is_available())"

True means Applio can use the GPU. False means it will use the CPU, usually because the NVIDIA driver is too old for the CUDA 12.8 build of PyTorch that Applio installs.

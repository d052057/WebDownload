WebAngular Project Setup Reference

This document explains how to create a full-stack project with Angular 21 frontend and .NET 9 backend.

1. Create Solution Folder and Solution

mkdir webangular
cd webangular
dotnet new sln -n webangular

2. Create .NET 9 Backend (Web API)

dotnet new webapi -n webangular.server
dotnet sln add webangular.server/webangular.server.csproj

# Optional: clean template controllers
del webangular.server\Controllers\WeatherForecastController.cs
del webangular.server\WeatherForecast.cs

3. Create Angular 21 Frontend

ng new webangular.client --routing --style=scss --skip-tests

4. Add Proxy Configuration

cd webangular.client
echo {
  "/api": {
    "target": "https://localhost:5001",
    "secure": false,
    "changeOrigin": true,
    "logLevel": "debug"
  }
} > proxy.conf.json

powershell -Command "(gc angular.json) -replace '\"options\": {','\"options\": {\n        \"proxyConfig\": \"proxy.conf.json\",' | Out-File angular.json -encoding UTF8"

5. Build Angular into Backend wwwroot

cd webangular.client
ng build --prod --output-path ../webangular.server/wwwroot

6. Optional Pre-Build Angular Step in Backend

powershell -Command "Add-Content webangular.server\webangular.server.csproj '\n  \n  \n'"

7. Minimal Program.cs

var builder = WebApplication.CreateBuilder(args);

builder.Services.AddControllers();
builder.Services.AddEndpointsApiExplorer();
builder.Services.AddSwaggerGen();
builder.Services.AddCors(options =>
{
    options.AddDefaultPolicy(policy =>
    {
        policy.WithOrigins("http://localhost:4200")
              .AllowAnyHeader()
              .AllowAnyMethod();
    });
});

var app = builder.Build();

if (app.Environment.IsDevelopment())
{
    app.UseSwagger();
    app.UseSwaggerUI();
}

app.UseCors();
app.UseHttpsRedirection();
app.UseAuthorization();
app.MapControllers();
app.UseDefaultFiles();
app.UseStaticFiles();
app.Run();

8. Run the Project

Backend
cd webangular.server
dotnet run
Angular Dev Server (with proxy)
cd webangular.client
ng serve

9. Folder Structure

webangular/
├─ webangular.client/
│   └─ proxy.conf.json
├─ webangular.server/
│   └─ wwwroot/
└─ webangular.sln

Now you can open webangular.sln in VS2022, set the backend as startup project, and run Angular separately or integrated with wwwroot.

🎵 Applio Voice Inference with Volume Control

Turn a vocal recording into your trained voice, with pitch and volume settings. Run it from anywhere; it finds the newest model of the voice by itself.

The script

infer_voice.bat
@echo off
setlocal EnableExtensions

rem ==========================================================================
rem  infer_voice.bat  -  turn a vocal recording into your Applio voice
rem
rem  Usage:   infer_voice.bat "C:\vocals\acapella.wav" [MODEL_NAME]
rem           (or drag the audio file onto this .bat)
rem
rem  The input should be a vocals-only recording, not a full song. To split a
rem  song first, use swap_voice.bat or the Splitter page.
rem  The result is saved next to the input file as: name [MODEL].wav
rem ==========================================================================

rem ---------------------------- SETTINGS ------------------------------------
set "APPLIO_DIR=C:\Tools\Applio"
rem Voice name = the folder name under Applio\logs
set "MODEL=myvoice"
rem Semitones, -24 to 24. About +12 for a man's song to a woman's voice, -12 for the opposite.
set "PITCH=0"
rem 0 to 1. Higher = closer to the trained voice but can sound rougher.
set "INDEX_RATE=0.5"
rem Make the converted voice louder or quieter, in dB. 0 = leave as is.
rem If the result sounds distorted, lower this number.
set "GAIN_DB=0"
rem --------------------------------------------------------------------------

if "%~1"=="" (
    echo Usage: infer_voice.bat "C:\vocals\acapella.wav" [MODEL_NAME]
    goto :fail
)
set "INPUT=%~f1"
if not "%~2"=="" set "MODEL=%~2"
set "OUTPUT=%~dpn1 [%MODEL%].wav"

if not exist "%INPUT%" (
    echo ERROR: input file not found: %INPUT%
    goto :fail
)
if not exist "%APPLIO_DIR%\env\python.exe" (
    echo ERROR: Applio not found in %APPLIO_DIR%. Edit APPLIO_DIR at the top of this file.
    goto :fail
)

rem Newest model file of this voice, for example myvoice_150e_900s.pth
set "LATEST="
for /f "delims=" %%F in ('dir /b /o:d "%APPLIO_DIR%\logs\%MODEL%\%MODEL%_*e_*s.pth" 2^>nul') do set "LATEST=%%F"
if not defined LATEST (
    echo ERROR: no %MODEL%_*e_*s.pth found in %APPLIO_DIR%\logs\%MODEL%
    echo        Train the voice first, or check MODEL.
    goto :fail
)

rem The index is optional. Without it the voice still works, a little less like you.
set "IDX=%APPLIO_DIR%\logs\%MODEL%\%MODEL%.index"
set "IDX_RATE=%INDEX_RATE%"
if not exist "%IDX%" (
    echo Note: no index file found, converting without it.
    set "IDX="
    set "IDX_RATE=0"
)

set "GAINARGS="
if not "%GAIN_DB%"=="0" set "GAINARGS=--post-process --gain --gain-db %GAIN_DB%"

echo.
echo Voice : %MODEL%  [%LATEST%]
echo Input : %INPUT%
echo Pitch : %PITCH%   Index rate: %IDX_RATE%   Gain: %GAIN_DB% dB
echo.

if exist "%OUTPUT%" del /q "%OUTPUT%"
pushd "%APPLIO_DIR%"
env\python.exe core.py infer --input-path "%INPUT%" --output-path "%OUTPUT%" --pth-path "logs\%MODEL%\%LATEST%" --index-path "%IDX%" --pitch %PITCH% --index-rate %IDX_RATE% --f0-method rmvpe --split-audio %GAINARGS%
popd

rem Applio can end without an error and still write nothing, so check the file.
if not exist "%OUTPUT%" (
    echo ERROR: Applio did not create the output file. Read its messages above.
    goto :fail
)

echo.
echo ==========================================================
echo  DONE. Saved: %OUTPUT%
echo ==========================================================
echo.
pause
exit /b 0

:fail
echo.
echo ==========================================================
echo  STOPPED. Fix the problem shown above, then run this again.
echo ==========================================================
echo.
pause
exit /b 1

How to use it

  1. Press Download infer_voice.bat and save it anywhere. If Applio is not in C:\Tools\Applio, edit APPLIO_DIR at the top.
  2. Have a vocals-only recording, such as a WAV file of just the singing.
  3. Run it with the file and the voice name, or drag the file onto the script:
    Command Prompt
    infer_voice.bat "C:\vocals\acapella.wav" myvoice
  4. The result is saved next to the input as acapella [myvoice].wav.

Settings at the top of the script

MODELThe voice name, the folder under Applio\logs.
PITCHSemitones from -24 to 24. About 12 moves a man's song to a woman's voice, -12 the opposite, 0 keeps the range.
INDEX_RATE0 to 1. Higher is closer to the trained voice but can sound rougher. It is set to 0 automatically when there is no index file.
GAIN_DBVolume of the converted voice in dB. 0 leaves it alone. Try 6 for louder; if it sounds distorted, lower it.
Tip. The input must be the voice alone. A full song with instruments gives poor results. To split a song first, use the Splitter page, or use the Voice Swap guides, which do the splitting, the conversion and the mixing for you.

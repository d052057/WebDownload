🎵 Voice Cover Inference Script

Adjust your paths, pitch shift (e.g., use 12 to raise an octave for female keys, -12 to drop an octave for male keys), and configure your VOLUME_BOOST level before copying this batch code into your command line.

                                @echo off
                                :: ==========================================
                                ::     INFERENCE PATHS & VOLUME VARIABLES
                                :: ==========================================
                                set APPLIO_DIR=c:\tools\applio
                                set MODEL_NAME=MyCustomVoice

                                :: --- Audio File Setup ---
                                set INPUT_AUDIO=assets\audios\input_song_vocals.wav
                                set OUTPUT_AUDIO=assets\audios\final_voice_cover.wav

                                :: --- Voice Tuning Parameters ---
                                set PITCH_CHANGE=0
                                set PITCH_ALGO=rmvpe
                                set INDEX_RATE=0.75

                                :: --- Volume Amplification Control ---
                                :: (Increase this number to turn up your custom voice volume)
                                set VOLUME_BOOST=6.0

                                :: ==========================================
                                ::             EXECUTE INFERENCE
                                :: ==========================================
                                echo [Processing] Navigating to Applio folder...
                                cd /d "%APPLIO_DIR%"

                                echo [Processing] Applying %MODEL_NAME% voice model onto audio track...
                                env\python.exe core.py infer --model_name "%MODEL_NAME%.pth" --index_path "logs\%MODEL_NAME%\added_index.index" --input_path "%INPUT_AUDIO%" --output_path "%OUTPUT_AUDIO%" --output_gain %VOLUME_BOOST% --pitch_change %PITCH_CHANGE% --pitch_algorithm "%PITCH_ALGO%" --index_rate %INDEX_RATE%

                                echo.
                                echo =======================================================
                                echo Success! Your volume-boosted voice file is ready at:
                                echo "%APPLIO_DIR%\%OUTPUT_AUDIO%"
                                echo =======================================================
                                pause
💡 Audio Separation Tip

For the best results, make sure your INPUT_AUDIO points strictly to an isolated vocal track (acapella) rather than a full track with background instruments. You can use Applio's built-in vocal separation tab first if you need to split the music from the voice!

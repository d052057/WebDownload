FFmpeg Subtitle Embedding Guide

Quick reference for embedding subtitles into MP4, WebM, and MKV using FFmpeg.

Embed Subtitles into MP4 (mov_text)

MP4 requires mov_text subtitles. SRT must be converted automatically.

ffmpeg -i input.mp4 -i subs.srt -c:v copy -c:a copy -c:s mov_text output.mp4

Embed Subtitles into WebM (WebVTT)

WebM only supports WebVTT. Convert SRT first if needed.

ffmpeg -i subs.srt subs.vtt
ffmpeg -i input.webm -i subs.vtt -c:v copy -c:a copy -c:s webvtt output.webm

Embed Subtitles into MKV (any format)

MKV accepts SRT, ASS, SSA, VTT, PGS, and more.

ffmpeg -i input.mkv -i subs.srt -c copy output.mkv

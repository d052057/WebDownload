Applio High-Fidelity Voice Swap (Keep Background Music)

Replaces the singer in a song with your trained voice and keeps the background music. It uses the slower, higher-quality Demucs model and saves a 320k MP3.

The script

swap_voice_audio.bat
@echo off
setlocal EnableExtensions

rem ==========================================================================
rem  swap_voice.bat  -  replace the singer with your Applio voice, keep the music
rem
rem  Usage:   swap_voice.bat "C:\songs\song.mp4" [MODEL_NAME]
rem           (or drag the file onto this .bat)
rem
rem  1 Extract the audio        (ffmpeg)
rem  2 Split voice and music    (Demucs, the same tool as the Splitter page)
rem  3 Convert the voice        (Applio)
rem  4 Mix new voice + music    (ffmpeg)
rem  5 Save an MP3 of the song with the new voice
rem ==========================================================================

rem ---------------------------- SETTINGS ------------------------------------
set "APPLIO_DIR=C:\Tools\Applio"
set "DEMUCS_EXE=C:\Tools\demucs314\Scripts\demucs.exe"
set "OUTPUT_DIR=C:\voice-swap"
rem Voice name = the folder name under Applio\logs
set "MODEL=myvoice"
rem audio = an MP3 only. video = a new video, if the file has a picture.
set "OUTPUT=audio"
rem htdemucs = faster.  htdemucs_ft = better separation, much slower.
set "DEMUCS_MODEL=htdemucs_ft"
rem cpu, or cuda if a working NVIDIA GPU is installed.
set "DEVICE=cpu"
rem Semitones, -24 to 24. About +12 for a man's song to a woman's voice, -12 for the opposite.
set "PITCH=0"
rem 0 to 1. Higher = closer to the trained voice but can sound rougher.
set "INDEX_RATE=0.5"
rem Loudness of the new voice and of the music in the mix, in dB. 0 = unchanged.
set "VOICE_DB=0"
set "MUSIC_DB=0"
rem Bitrate of the MP3 or of the video's audio.
set "BITRATE=320k"
rem --------------------------------------------------------------------------

if "%~1"=="" (
    echo Usage: swap_voice.bat "C:\songs\song.mp4" [MODEL_NAME]
    goto :fail
)
set "INPUT=%~f1"
set "BASENAME=%~n1"
set "INEXT=%~x1"
if not "%~2"=="" set "MODEL=%~2"

rem ---- Checks before starting ----
if not exist "%INPUT%" (
    echo ERROR: input file not found: %INPUT%
    goto :fail
)
if not exist "%APPLIO_DIR%\env\python.exe" (
    echo ERROR: Applio not found in %APPLIO_DIR%. Edit APPLIO_DIR at the top of this file.
    goto :fail
)
if not exist "%DEMUCS_EXE%" (
    echo ERROR: Demucs not found: %DEMUCS_EXE%. Edit DEMUCS_EXE at the top of this file.
    goto :fail
)
ffmpeg -version >nul 2>&1
if errorlevel 1 (
    echo ERROR: ffmpeg was not found. Add the folder with ffmpeg.exe to your PATH.
    goto :fail
)

set "LATEST="
for /f "delims=" %%F in ('dir /b /o:d "%APPLIO_DIR%\logs\%MODEL%\%MODEL%_*e_*s.pth" 2^>nul') do set "LATEST=%%F"
if not defined LATEST (
    echo ERROR: no %MODEL%_*e_*s.pth found in %APPLIO_DIR%\logs\%MODEL%
    echo        Train the voice first, or check MODEL.
    goto :fail
)

rem The index is optional. Without it the voice still works, a little less like you.
set "IDX=%APPLIO_DIR%\logs\%MODEL%\%MODEL%.index"
set "IDX_RATE=%INDEX_RATE%"
if not exist "%IDX%" (
    echo Note: no index file found, converting without it.
    set "IDX="
    set "IDX_RATE=0"
)

rem Does the input have a picture? Decided by the file type, as the Splitter page does.
set "HASVIDEO="
for %%E in (.mp4 .m4v .mov .mkv .webm .avi) do if /i "%INEXT%"=="%%E" set "HASVIDEO=1"
set "KIND=%OUTPUT%"
if /i "%KIND%"=="video" if not defined HASVIDEO (
    echo Note: this file has no picture, so an MP3 is made instead of a video.
    set "KIND=audio"
)
set "OUT_EXT=.mp3"
if /i "%KIND%"=="video" (
    set "OUT_EXT=.mp4"
    if /i "%INEXT%"==".mkv" set "OUT_EXT=.mkv"
)

if not exist "%OUTPUT_DIR%" mkdir "%OUTPUT_DIR%"
set "FINAL=%OUTPUT_DIR%\%BASENAME% [voice swap]%OUT_EXT%"
set "WORK=%TEMP%\applio_swap_%RANDOM%"
mkdir "%WORK%"

echo.
echo Input  : %INPUT%
echo Voice  : %MODEL%  [%LATEST%]
echo Split  : %DEMUCS_MODEL% on %DEVICE%     Pitch: %PITCH%
echo Output : %FINAL%
echo.
echo This can take several minutes, longer without a GPU. Do not close the window.

rem ================= 1. Extract the audio =================
echo.
echo ===== [1/5] Extract the audio =====
ffmpeg -y -v error -i "%INPUT%" -vn -map 0:a:0 -ac 2 -ar 44100 -c:a pcm_s16le "%WORK%\input.wav"
if not exist "%WORK%\input.wav" (
    echo ERROR: could not read the audio of this file.
    goto :fail
)

rem ================= 2. Split voice and music =================
echo.
echo ===== [2/5] Split voice and music =====
"%DEMUCS_EXE%" -n %DEMUCS_MODEL% --two-stems vocals -d %DEVICE% --filename "{stem}.{ext}" -o "%WORK%\demucs" "%WORK%\input.wav"
set "VOCALS=%WORK%\demucs\%DEMUCS_MODEL%\vocals.wav"
set "MUSIC=%WORK%\demucs\%DEMUCS_MODEL%\no_vocals.wav"
if not exist "%VOCALS%" (
    echo ERROR: Demucs did not make vocals.wav. Read its messages above.
    goto :fail
)
if not exist "%MUSIC%" (
    echo ERROR: Demucs did not make no_vocals.wav. Read its messages above.
    goto :fail
)

rem ================= 3. Convert the voice =================
echo.
echo ===== [3/5] Convert the voice with Applio =====
pushd "%APPLIO_DIR%"
env\python.exe core.py infer --input-path "%VOCALS%" --output-path "%WORK%\converted.wav" --pth-path "logs\%MODEL%\%LATEST%" --index-path "%IDX%" --pitch %PITCH% --index-rate %IDX_RATE% --f0-method rmvpe --split-audio
popd
if not exist "%WORK%\converted.wav" (
    echo ERROR: Applio did not create the converted voice. Read its messages above.
    goto :fail
)

rem ================= 4. Mix =================
echo.
echo ===== [4/5] Mix the new voice with the music =====
rem amix normalize=0 keeps the levels as set; alimiter stops clipping.
ffmpeg -y -v error -i "%MUSIC%" -i "%WORK%\converted.wav" -filter_complex "[0:a]aformat=sample_rates=44100:channel_layouts=stereo,volume=%MUSIC_DB%dB[m];[1:a]aformat=sample_rates=44100:channel_layouts=stereo,volume=%VOICE_DB%dB[v];[m][v]amix=inputs=2:duration=first:dropout_transition=0:normalize=0,alimiter=limit=0.95[mix]" -map "[mix]" -c:a pcm_s16le "%WORK%\mix.wav"
if not exist "%WORK%\mix.wav" (
    echo ERROR: the mix failed. Read the ffmpeg message above.
    goto :fail
)

rem ================= 5. Save =================
echo.
echo ===== [5/5] Save =====
if /i "%KIND%"=="video" (
    ffmpeg -y -v error -i "%INPUT%" -i "%WORK%\mix.wav" -map 0:v:0 -map 1:a:0 -c:v copy -c:a aac -b:a %BITRATE% "%FINAL%"
) else (
    ffmpeg -y -v error -i "%WORK%\mix.wav" -vn -c:a libmp3lame -b:a %BITRATE% "%FINAL%"
)
if not exist "%FINAL%" (
    echo ERROR: could not write %FINAL%
    goto :fail
)

rmdir /s /q "%WORK%"
echo.
echo ==========================================================
echo  DONE. Saved: %FINAL%
echo ==========================================================
echo.
pause
exit /b 0

:fail
echo.
echo ==========================================================
echo  STOPPED. Fix the problem shown above, then run this again.
if defined WORK echo  Temporary files are kept in: %WORK%
echo ==========================================================
echo.
pause
exit /b 1

What it needs

  • Applio with a trained voice (see the training guide).
  • Demucs, the same separator the Splitter page uses. Set DEMUCS_EXE to the same path as Splitter:DemucsExecutablePath in appsettings.json.
  • ffmpeg in your PATH (a recent version, with the amix filter's normalize option).

How to use it

  1. Press Download swap_voice_audio.bat, save it anywhere and check APPLIO_DIR and DEMUCS_EXE at the top.
  2. Run it with the file and, if you like, the voice name; or drag the file onto the script:
    Command Prompt
    swap_voice_audio.bat "C:\songs\song.mp3" myvoice
  3. The MP3 is saved in C:\voice-swap as song [voice swap].mp3. Change OUTPUT_DIR to save elsewhere. Any audio file or video file works as the input.

It can take several minutes, longer without a GPU. Do not close the window; it says when it is done and stops with a message if a step fails.

How it works

  1. ffmpeg extracts the audio as a plain stereo WAV.
  2. Demucs splits it into vocals.wav and no_vocals.wav (the music).
  3. Applio converts vocals.wav to your voice.
  4. ffmpeg mixes the new voice with the music, without normalising the levels and with a limiter so it cannot clip.
  5. The result is saved as described above.

Demucs does the splitting because an ffmpeg phase trick such as pan=c0-c1 only cancels sounds panned to the centre; it cannot isolate a voice.

Settings at the top of the script

MODELThe voice name, the folder under Applio\logs.
OUTPUTaudio (default) makes an MP3. video makes a new video instead, for files that have a picture.
DEMUCS_MODELhtdemucs_ft (default here): the best separation, and much slower than htdemucs.
BITRATEMP3 quality, 320k by default.
DEVICEcpu, or cuda if a working NVIDIA GPU is installed.
PITCHSemitones from -24 to 24. About 12 moves a man's song to a woman's voice, -12 the opposite.
VOICE_DB / MUSIC_DBLoudness of the new voice and of the music in the mix, in dB. Raise VOICE_DB to make the voice stand out.

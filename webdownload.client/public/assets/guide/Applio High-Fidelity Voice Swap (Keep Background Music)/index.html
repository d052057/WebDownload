Applio Video Vocal Replacer (Music Preserved)

Extracts dialogue, runs the AI conversion with custom volume gain, and remuxes your voice back into the original MP4 background music bed.

🎵 Studio Mix-Extraction Script

Place your original.mp4 inside your Applio folder's assets\audios directory. Tweak the volume or pitch tuning fields below, copy the entire sequence, and execute it inside a command prompt.

@echo off :: ========================================================= :: PATHS, VOLUMES & VIDEO VARIABLES :: ========================================================= set APPLIO_DIR=c:\tools\applio set MODEL_NAME=MyCustomVoice :: --- Audio & Video Configuration --- set ORIGINAL_VIDEO=assets\audios\original.mp4 set EXTRACTED_VOCALS=assets\audios\extracted_vocals.wav set CONVERTED_AI_VOCALS=assets\audios\temp_boosted_ai_vocals.wav set FINAL_OUTPUT_VIDEO=assets\audios\final_replaced_cover.mp4 :: --- Voice Tuning Parameters --- set PITCH_CHANGE=0 set PITCH_ALGO=rmvpe set INDEX_RATE=0.75 :: --- Volume Boost Control --- :: (Increase this number to make your AI voice stand out more over the music) set VOLUME_BOOST=6.0 :: ========================================================= :: EXECUTE PIPELINE :: ========================================================= echo [Processing] Navigating to Applio directory... cd /d "%APPLIO_DIR%" echo [Processing] Step 1: Isolating original vocals from MP4 audio stream... :: Uses FFmpeg's built-in pan-pass filters to isolate center-channel vocals ffmpeg -i "%ORIGINAL_VIDEO%" -af "pan=mono|c0=c0-c1" "%EXTRACTED_VOCALS%" -y echo [Processing] Step 2: Passing extracted vocals through Applio AI Voice Model... env\python.exe core.py infer --model_name "%MODEL_NAME%.pth" --index_path "logs\%MODEL_NAME%\added_index.index" --input_path "%EXTRACTED_VOCALS%" --output_path "%CONVERTED_AI_VOCALS%" --output_gain %VOLUME_BOOST% --pitch_change %PITCH_CHANGE% --pitch_algorithm "%PITCH_ALGO%" --index_rate %INDEX_RATE% echo [Processing] Step 3: Merging new AI voice back into MP4 with original audio beds... :: Strips original center voice frequencies from the source video audio channel, then layers in the boosted AI voice ffmpeg -i "%ORIGINAL_VIDEO%" -i "%CONVERTED_AI_VOCALS%" -filter_complex "[0:a]pan=stereo|c0=c0|c1=c1[bg]; [bg][1:a]amix=inputs=2:duration=first:dropout_transition=2[audio_out]" -map 0:v:0 -map "[audio_out]" -c:v copy -c:a aac -b:a 192k "%FINAL_OUTPUT_VIDEO%" -y echo. echo ======================================================= echo Success! Your final video track with replaced vocals is ready: echo "%APPLIO_DIR%\%FINAL_OUTPUT_VIDEO%" echo ======================================================= pause
💡 Expert Separation Note

Step 1 filters center pan channels out to target vocal tracks. If your input video has heavy reverb or complex stereo vocal tracking, use Applio's graphic interface UVR tab with the MDX-Net / VR Architecture model first to save the clean instrumental stem, then use this script to layer your output audio seamlessly!

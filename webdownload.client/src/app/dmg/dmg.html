Guide: Create macOS Sequoia Bootable USB and DMG

Step 1: Download & Install Sequoia using gibMacOS

  1. Use gibMacOS to download InstallAssistant.pkg for macOS Sequoia 15.7.2.
  2. Copy the downloaded folder to your Mac Desktop.
  3. Open Terminal and run the following to install the Sequoia installer app into /Applications:
    4. sudo installer -pkg ~/Desktop/Sequoia15.7.2/InstallAssistant.pkg -target /
  4. Verify it exists: 
    ls /Applications | grep Sequoia
    You should see Install macOS Sequoia.app.

Step 2: Create Bootable USB

  1. Plug in a USB drive (≥16GB) and open Disk Utility.
  2. Erase the USB with:
    • Name: Sequoia15.7.2 (optional, it will be renamed)
    • Format: Mac OS Extended (Journaled)
    • Scheme: GUID Partition Map
  3. Use Terminal to create the bootable USB:
    4. sudo /Applications/Install\ macOS\ Sequoia.app/Contents/Resources/createinstallmedia --volume "/Volumes/Sequoia15.7.2"
  4. After completion, the USB will be renamed automatically to Install macOS Sequoia.

Step 3: Create a DMG Backup

  1. Once the USB is ready, you can create a DMG for backup.
  2. Run the following in Terminal to make a compressed DMG on your Desktop:
    3. sudo hdiutil create -volname "Sequoia15.7.2" -srcfolder "/Volumes/Install macOS Sequoia" -format UDZO ~/Desktop/Sequoia15.7.2.dmg
  3. Wait until Terminal shows: created: /Users/YourName/Desktop/Sequoia15.7.2.dmg

✅ Now you have a bootable USB and a DMG backup of macOS Sequoia 15.7.2 ready for installation or future use.

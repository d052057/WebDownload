Windows 11 USB Boot Repair Guide

Advanced Boot Recovery Methods

Manual boot repair using Windows 11 installation USB when automatic repair fails

When to Use This Guide

Problem: You have a Windows 11 installation USB and tried the "Repair your computer" option, but it didn't work.

Situation: Your hard disk has Windows 11 installed with data, but won't boot properly.

Solution: Manual boot repair using Command Prompt from the Windows 11 USB recovery environment.

What You Need

  • Windows 11 installation USB drive (bootable)
  • Non-bootable hard disk with Windows 11 and data still intact
  • Access to BIOS/UEFI to boot from USB
  • Basic knowledge of Command Prompt
⚠️ Important Notes
  • These commands will not delete your data
  • Back up critical files if possible before proceeding
  • Make sure you identify the correct disk and partitions
  • If unsure, stop and seek professional help

Getting Started

Initial Setup Boot from Windows 11 USB

  1. Insert the Windows 11 installation USB drive
  2. Restart your computer
  3. Press the boot menu key (usually F12, F10, F8, or ESC)
  4. Select the USB drive from the boot menu
  5. When Windows Setup appears, select your language and click "Next"
  6. Click "Repair your computer" (bottom left, NOT "Install now")
  7. Click "Troubleshoot"
  8. Click "Advanced options"
  9. Click "Command Prompt"
Tip: You may need to enter your BitLocker recovery key if your drive is encrypted.

Method 1 Automatic Boot Repair (Try This First)

This method uses Windows built-in tools to automatically fix boot problems.

Commands to Run:
bootrec /fixmbr
bootrec /fixboot
bootrec /scanos
bootrec /rebuildbcd
What Each Command Does:
  • bootrec /fixmbr - Fixes the Master Boot Record
  • bootrec /fixboot - Writes a new boot sector
  • bootrec /scanos - Scans all disks for Windows installations
  • bootrec /rebuildbcd - Rebuilds the Boot Configuration Data
If Successful: You'll see messages like "The operation completed successfully" for each command. Type exit and restart your computer.
If This Doesn't Work: Proceed to Method 2 below.

Method 2 Manual Boot Rebuild

This method manually identifies your Windows installation and rebuilds the boot files.

Step 1: Identify Your Disk and Partitions
diskpart
list disk
// Note the disk number of your Windows disk (usually Disk 0)

select disk 0
// Replace 0 with your disk number
list volume
// Look for: EFI partition (FAT32, ~100-500MB) and Windows partition (NTFS, large size)
Important: Take note of:
  • EFI System Partition: Usually 100-500MB, FAT32 format, may show as "System"
  • Windows Partition: Large NTFS partition containing your Windows installation
Step 2: Assign Drive Letters
select volume 2
// Replace 2 with the volume number of your EFI partition
assign letter=S

select volume 3
// Replace 3 with the volume number of your Windows partition
assign letter=W

exit
Step 3: Rebuild Boot Files
bcdboot W:\Windows /s S: /f UEFI

Where:

  • W:\Windows = Your Windows installation location
  • /s S: = Target EFI system partition
  • /f UEFI = Boot files format for UEFI systems
Success Message: "Boot files successfully created."
Step 4: Restart
exit
// Remove the USB drive and restart
If This Doesn't Work: Proceed to Method 3.

Method 3 Full EFI Partition Rebuild (Advanced)

Warning: This method recreates the EFI partition. Only use this if Methods 1 and 2 failed. This will not delete your Windows data.

Use this when the EFI partition is corrupted or missing entirely.

Step 1: Check Current Partitions
diskpart
list disk
select disk 0
// Replace 0 with your Windows disk number
list partition
// Check if you have an EFI partition (usually 100-500MB)
Step 2: Delete Old EFI Partition (If Exists and Corrupted)
select partition 1
// Replace 1 with the EFI partition number
delete partition override
// ONLY if you confirmed this is the small FAT32 EFI partition!
CRITICAL: Make absolutely sure you're deleting the correct partition! The EFI partition is small (100-500MB) and FAT32. DO NOT delete your Windows partition!
Step 3: Create New EFI Partition
// Shrink Windows partition to make space (if needed)
select partition 2
// Replace 2 with your Windows partition number
shrink desired=500 minimum=100

// Create new EFI partition
create partition efi size=500
format quick fs=fat32 label="System"
assign letter=S
list volume
// Verify the new EFI partition was created
Step 4: Identify Windows Partition
select partition 2
// Replace 2 with your Windows partition number
assign letter=W
exit
Step 5: Create Boot Files
bcdboot W:\Windows /s S: /f UEFI
Expected Output: "Boot files successfully created."
Step 6: Exit and Restart
exit
// Remove USB and restart your computer

Additional Boot Fixes

If Windows boots but has errors, run these commands from Command Prompt (Admin):

sfc /scannow
// Scans and repairs Windows system files

DISM /Online /Cleanup-Image /RestoreHealth
// Repairs the Windows image

These commands can take 15-30 minutes to complete.

Sometimes Secure Boot can prevent booting after repairs:

  1. Restart and enter BIOS/UEFI (press F2, F10, DEL, or F12)
  2. Find "Secure Boot" settings (usually under Security or Boot tab)
  3. Disable Secure Boot
  4. Save and Exit
  5. Try booting again
You can re-enable Secure Boot after Windows is working properly.

Corrupted BIOS settings can cause boot failures:

  1. Enter BIOS/UEFI settings
  2. Find "Load Optimized Defaults" or "Reset to Default"
  3. Confirm and save
  4. Make sure boot mode is set to UEFI (not Legacy)
  5. Set your hard disk as first boot device
  6. Save and Exit

Physical connection issues can prevent booting:

  • Power off the computer completely
  • Open the case and check SATA/power cables
  • Disconnect and reconnect both cables firmly
  • Try different SATA ports on motherboard
  • Replace SATA cable if available
Only do this if you're comfortable opening your computer case.

Common Issues and Solutions

"Element not found" or "Access denied" errors

Solution:

  • Make sure you're selecting the correct partition numbers
  • The EFI partition should be FAT32 format
  • The Windows partition should be NTFS format
  • Use list volume to double-check before proceeding
"Total identified Windows installations: 0"

Solution:

  • Your Windows installation may be on a different disk
  • Run diskpart → list disk to see all disks
  • Select each disk and check for Windows partition
  • Windows folder should exist in the root directory (C:\Windows or W:\Windows)
Computer boots to USB instead of hard disk

Solution:

  • Remove the USB drive before restarting
  • Enter BIOS and change boot order (hard disk first)
  • Make sure boot mode is set to UEFI, not Legacy
Still can't boot after all methods

Possible causes:

  • Hard drive may be failing (check SMART status)
  • Windows system files may be corrupted beyond repair
  • Motherboard BIOS may need updating
  • Consider backing up data and doing clean Windows install

Quick Command Reference

Command Purpose

list disk Show all hard disks
list volume Show all partitions/volumes

assign letter=X Assign drive letter to partition
detail volume Show detailed partition info

bcdboot X:\Windows /s Y: /f UEFI Copy boot files to EFI partition

Success Indicators

If the repair was successful, you should see:

  • Windows boots normally without the USB drive
  • All your files and programs are accessible
  • No boot error messages appear
  • System runs as it did before the boot issue

Prevention Tips

To avoid boot problems in the future:

Regular Backups

Create system images regularly using Windows Backup or third-party tools like Acronis

Keep Windows Updated

Install Windows updates regularly to prevent system file corruption

Use Antivirus

Keep antivirus software active to prevent malware that can damage boot files

Safe Shutdown

Always shut down properly and use a UPS to protect against power failures

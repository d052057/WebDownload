📚 Git LFS Lessons Learned

Handling Large Files in Git - A Complete Guide

🚨 The Problem

Error Encountered:

GH001: Large files detected. You may want to try Git Large File Storage

GitHub blocks files larger than 100MB. In our case, avcodec-62.dll was 100.45MB, which exceeded the limit.

✅ The Solution: Git LFS

What is Git LFS?

Git Large File Storage (LFS) replaces large files with small pointer files in your repository, while storing the actual file contents on a remote server. This keeps your repository fast and efficient.

🔧 Initial Setup (For New Projects)

1 Install Git LFS
# Download from https://git-lfs.github.com/
# Or use package manager (Windows with Chocolatey):
choco install git-lfs
2 Initialize your project
cd YourProjectFolder
git init
3 Setup Git LFS
git lfs install
git lfs track "*.dll" # Track DLL files
git lfs track "*.mp4" # Track video files
git lfs track "*.zip" # Track archives
4 Commit LFS configuration
git add .gitattributes
git commit -m "Configure Git LFS"
5 Add your files and push
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/username/repo.git
git push -u origin master
💡 Pro Tip: Always set up Git LFS BEFORE adding large files to your repository!

🔄 Recovery (If You Already Committed Large Files)

⚠️ Warning: If you've already committed large files without LFS, they're stuck in your Git history. You need to clean the history first.
1 Delete the .git folder (Nuclear Option - Simplest)
cd YourProjectFolder
Remove-Item -Recurse -Force .git

This removes all Git history. Your files stay intact, but all commit history is gone.

2 Start fresh with Git LFS
git init
git lfs install
git lfs track "*.dll"
git add .gitattributes
git add .
git commit -m "Initial commit with Git LFS"
3 Verify LFS is working
git lfs ls-files

You should see your large files listed here!

4 Push to GitHub
git remote add origin https://github.com/username/repo.git
git push -u origin master

🎨 Using Visual Studio 2022

Visual Studio 2022 has built-in Git support, but you still need to set up LFS via command line first:

1 Run LFS commands in PowerShell first
git lfs install
git lfs track "*.dll"
2 Use VS2022 for everything else
  • Open your solution in Visual Studio 2022
  • Go to View → Git Changes (Ctrl+0, G)
  • Stage files by clicking the + button
  • Enter commit message and click Commit All
  • Click Push to push to GitHub
3 Add remote repository (if needed)
  • Go to Git → Manage Remotes
  • Click Add
  • Enter Name: origin
  • Enter URL: https://github.com/username/repo.git

📁 Common File Types to Track with LFS

# Design files git lfs track "*.psd"
git lfs track "*.ai"
git lfs track "*.sketch"
# Media files
git lfs track "*.mp4"
git lfs track "*.mov"
git lfs track "*.avi"
# Archives
git lfs track "*.zip"
git lfs track "*.rar"
git lfs track "*.7z"
# Binary files
git lfs track "*.dll"
git lfs track "*.exe"
git lfs track "*.so"
# Database files
git lfs track "*.db"
git lfs track "*.sqlite"

✅ CORRECT ORDER (The Solution)

1 git lfs install
✓ Initialize LFS
2 git lfs track "*.dll"
✓ Configure which files use LFS
3 git add .gitattributes
✓ Commit LFS config FIRST
4 git commit -m "Configure LFS"
5 git add .
✓ Large files go through LFS now
6 git commit -m "Add files"
7 git push
✓ SUCCESS - Files are LFS pointers

🎯 Adding Large File to existing Git Lfs

Repeat step 2, 3, 4 and 5
git lfs track "*.new file type"
git add .gitattributes
git commit -m "Configure new LFS"
git add .
Last step, commit from VS2022 or this comment line below
git push

🎯 Key Takeaways

  • Setup LFS BEFORE adding large files - This prevents issues entirely
  • Files over 100MB cannot be pushed to GitHub without LFS
  • If you already committed large files, clean your Git history - The easiest way is to delete .git and start fresh
  • Verify LFS is working - Use git lfs ls-files to confirm files are tracked
  • The .gitattributes file must be committed BEFORE large files
  • Visual Studio 2022 can be used after LFS is set up via command line
